# Changelog

The source history follows Semantic Versioning. npm availability is recorded separately because the initial package publication requires external registry ownership.

## 0.3.0 — 2026-09-01

- Added Schema 3 evidence provenance with explicit completeness, privilege, and sensitivity labels.
- Added framework-neutral evidence-provider orchestration and stable provider failure semantics.
- Added opt-in, pre-navigation closed Shadow DOM instrumentation for Playwright.
- Added nested, dynamic, cross-origin, churn, migration, redaction, and TQ1 gym coverage for the new evidence layer.
- Added guarded, provenance-enabled release automation with tag, changelog, browser-matrix, and tarball-content gates.
- Raised the Puppeteer adapter peer range to Puppeteer 25, removing the vulnerable downloader dependency chain from the development graph.
- Removed TypeScript compiler cache data from the Puppeteer package tarball.

## 0.2.0 — source preview (npm unpublished)

- Added ARIA perception trees, hashed pixel attachments, and mandatory pixel masks for redacted screenshots.
- Added the optional Puppeteer adapter and public adapter conformance kit.
- Added schema 2 with explicit schema-1 migration and historical fixtures.
- Added trusted structural redaction with graph-preservation validation.
- Added scale, repeated-session, hostile-hook, rendering-boundary, and detached-frame fixtures.

## 0.1.0 — unreleased preview baseline

- Added the framework-neutral `domstamp` core.
- Added the optional Playwright adapter.
- Added the optional TQ1 lossless codec.
- Added deterministic Dockerized conformance and chaos gyms.
