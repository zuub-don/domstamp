## The contract in one sentence

Domstamp asks a typed adapter to capture accessible browser state, validates the resulting graph, applies bounded orchestration, and returns a driver-independent snapshot.

It is intentionally split into four packages:

<div class="package-table" role="region" aria-label="Domstamp package responsibilities" tabindex="0">
  <table>
    <thead>
      <tr><th>Package</th><th>Owns</th><th>Runtime dependencies</th></tr>
    </thead>

        <td data-label="Package"><code>domstamp</code></td>
        <td data-label="Owns">Schema, configuration, orchestration, evidence providers, validation, plugins</td>
        <td data-label="Runtime dependencies">None</td>
      </tr>
      <tr>
        <td data-label="Package"><code>@domstamp/playwright</code></td>
        <td data-label="Owns">Playwright adapter, ARIA perception capture, and pixel evidence</td>
        <td data-label="Runtime dependencies"><code>playwright-core</code> peer and YAML parser</td>
